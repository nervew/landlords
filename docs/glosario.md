# Glosario

| Término | Definición |
| --- | --- |
| Actor | Identidad resuelta desde la sesión, con indicador de administrador y agencias permitidas. |
| Agencia o inmobiliaria | Organización que administra un perfil y propiedades. |
| Auditoría | Registro append-only de una acción sensible, su actor y entidad afectada. |
| Better Auth | Librería responsable de cuentas, contraseñas, sesiones y recuperación. |
| Borrador (`draft`) | Propiedad editable que todavía no es pública. |
| Inmobiliaria pendiente (`pending`) | Agencia cuyos envíos requieren moderación. |
| Inmobiliaria verificada (`verified`) | Agencia cuyos envíos se publican directamente. |
| Inmobiliaria suspendida (`suspended`) | Agencia bloqueada para nuevos envíos. |
| Invitación | Enlace temporal de un solo uso para asociar un correo a una inmobiliaria. |
| Membresía | Relación entre usuario e inmobiliaria, con rol `owner` o `editor`. |
| Moderación | Decisión administrativa de aprobar o rechazar una propiedad. |
| Outbox | Tabla que persiste correo antes de entregarlo y conserva reintentos. |
| Propiedad publicada (`published`) | Inmueble visible en catálogo, detalle y sitemap. |
| Rechazada (`rejected`) | Propiedad devuelta con una razón administrativa. |
| Revisión (`pending_review`) | Propiedad esperando decisión de plataforma. |
| SPEC | Contrato de implementación y aceptación mantenido en `NORTH/SPECS/`. |
| WebP | Formato al que se convierten las imágenes antes de almacenarlas. |
